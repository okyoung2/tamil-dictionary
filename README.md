# 타밀 소사전

타밀 문자·로마자로 찾는 타밀어 학습 사전입니다.

- 한국어 풀이 핵심 어휘 (나디 잎·점성술·시바·싯다·성지·가족·숫자 등)
- 사전 표제어 11만여 개: University of Madras *Tamil Lexicon*(1924–1936), M. Winslow(1862), Wiktionary, WHO 싯다 의학 표준 용어(2023)
- 문장 속 형태(활용형)로 기본형 찾기, 타밀 자모표(자음+모음 216자), 야자잎 글씨 읽는 법

영어 풀이는 크롬의 **한국어로 번역**(주소창 번역 아이콘 또는 마우스 오른쪽 버튼)으로 한국어로 볼 수 있습니다. 타밀어 표제어와 한국어 화면은 번역되지 않도록 막아 두었습니다. 카카오톡 안에서 열면 번역 기능이 없으니 크롬이나 사파리로 여세요.
